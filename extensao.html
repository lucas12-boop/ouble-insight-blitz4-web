Consultando versão disponível…

Não é necessário reinstalar o robô/site. Apenas a extensão do Chrome é atualizada quando uma nova versão está disponível.

Como atualizar

1. Baixe a versão anunciada acima, quando houver uma atualização publicada.

2. Extraia a pasta e abra chrome://extensions.

3. Substitua ou recarregue a extensão com Carregar sem compactação.

4. Atualize a aba do TipMiner com Ctrl + R para carregar o leitor novo.

Extensões instaladas manualmente não recebem atualização automática da Chrome Web Store. A distribuição via loja seria necessária para essa experiência.
