# Blitz4 LAB Chrome Extension v0.1

Instalação: baixe esta pasta (ou ZIP do repositório), abra chrome://extensions, ative Modo do desenvolvedor, clique Carregar sem compactação e escolha a pasta extensao-blitz4-lab. Abra ou recarregue a página Blitz4 Double e clique no ícone da extensão.

Captura exclusivamente local: NÃO transmite à Railway, não aposta, não usa credenciais. Exportar JSON para auditoria de 50 resultados.

O branco foi identificado como .sm-box.white svg nas capturas. Números usam .number. Se a lista for reordenada ou tiver números repetidos sem sobreposição única, registra lacuna e NÃO inventa resultado. Horários são de observação, não oficiais. Não garante 24h ou funcionamento com aba fechada.
